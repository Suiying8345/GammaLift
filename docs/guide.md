# GammaLift 功能详解

主 README 见 [README.md](../README.md)。本文承载详细功能说明、使用提示与技术细节。

## 功能总览

### 软件调节（Gamma LUT）

亮度、对比度、Gamma 写入显卡的每显示器 Gamma LUT，立即生效，不依赖显示器是否支持 DDC/CI。这是默认通道，也是「提亮暗部」的主要手段。

### RGB 通道独立

与经典 Gamma Panel 一致：可以联动调整三个通道，也可以单独调红、绿、蓝，用于简易色温校正。联动模式下三个滑杆同步，单通道模式下只改所选通道。

### 硬件调节（DDC/CI）

直接控制显示器面板自身的亮度、对比度与饱和度，效果等同于在显示器 OSD 菜单里调节，需显示器支持 DDC/CI。滑块与数值框均可输入。硬件调节区（界面标题为 `硬件调节 (DDC/CI)`）收在「更多」分组里，默认会按显示器能力自动展开：选中显示器支持 DDC/CI 时展开，不支持时收起（仍保留「更多」入口，展开可看到原因）；切换显示器或重新启动会重新判断。「设置 › 显示器」里可以改成固定「启动时展开」，两个选项互斥。自动展开需要读取 DDC/CI，部分显示器读取时可能短暂闪屏或变慢。

饱和度只能走硬件通道：Gamma LUT 是单通道映射，物理上无法改变饱和度（那需要跨通道混色）。显示器若不支持会显示提示，笔记本内屏通常不支持。

### 多显示器独立

顶部下拉选择目标显示器，每台的设置独立保存。多屏时可勾选「同步调节所有显示器」。设置按显示器硬件 ID 记忆，调换接口或重新插拔不会错配。

### 预设与全局热键

保存多套预设（如白天、夜晚、提亮暗部），每套记录所有显示器的状态。选中预设立即应用；有未保存修改时，先选择保存、丢弃或取消。预设区提供「保存 / 新建」两个按钮；改名、排序与删除集中在「循环切换预设」行右侧的「编辑…」里。热键框和触发方式与保存 / 新建同处一行，热键框右侧的 × 可一键清除绑定。

「循环切换预设」行最右侧的「编辑…」打开统一的预设编辑窗口：可拖动条目，或选中后点「上移 / 下移」调整顺序；在下方「名称」框可直接改名；点「删除」可移除选中预设。点「确定」后，顺序、名称和删除才一起生效，并同步到主界面下拉、托盘菜单与循环切换；点「取消」会放弃这次的全部修改。列表中的「当前」标记表示正在生效的预设；若它还有未保存的参数修改，删除前会再次确认。删除当前预设后会自动切到剩余列表的第一项。编辑只改变列表位置、名称或预设集合，不改变各预设的参数和热键归属。

每套预设的热键旁可选择单击、双击、长按；同一个组合键可以分配给不同手势，但同键同手势不能重复绑定。长按持续 400 ms 后触发一次；双击时间跟随 Windows。只有单击绑定时立即响应；同键还绑定双击时，单击会等待双击间隔结束；同键还绑定长按时，短按在松开时触发。按住产生的自动重复不会反复切换。F12 是系统保留键，不能绑定。

`配置文件 (可绑定全局热键一键切换)` 分组上方的「循环切换预设」可另绑一个热键，依次切换现有列表，末尾回到第一项；默认不绑定。循环动作也支持三种手势，与各预设一起检查冲突。热键使用系统独占注册，但不保证所有游戏的 Raw Input / DirectInput 都屏蔽按键，需在实际游戏中检查是否与游戏操作冲突。

切换时若主窗口在托盘隐藏，会弹自绘置顶提示窗告知当前预设；窗口可见时默认只走状态栏。「设置 › 托盘与通知」提供总开关，以及应用预设、前台也显示提示、隐藏到托盘三项开关；打开「前台也显示提示」后，主窗口可见时应用预设也会弹出置顶提示窗。关闭总开关会保留子项偏好；错误信息和未保存确认仍然显示。这些提示不使用 Windows 原生系统通知。

### 单屏参数分享码

分享码按钮在软件调节区右上角，与「重置」并排。分享码只反映当前选中显示器的当前参数：默认参数时复制按钮不可用，拖动滑杆或应用预设后即可复制。码中只含该显示器 RGB 三通道的亮度、对比度、Gamma 与联动状态，不含名称、热键、显示器硬件 ID、ICC 基线、存储地址或开机启动项。

码采用紧凑格式 `GL2…`：RGB 联动时 11 个字符，分通道时 22 个字符。点「复制分享码」会写入剪贴板并弹出置顶提示。

导入时点「导入分享码」，在弹出的窗口里粘贴分享码；校验通过后点「导入」会立即应用到当前显示器，无效码会在窗口内标红说明。导入只改当前实时参数，不会自动保存到预设，需要时再点「保存」。分享码全程离线，无账号或云端；短校验用于发现抄录错误，不是加密或签名。

### 曲线预览

实时绘制当前 Gamma 曲线，调节滑杆时同步更新，便于判断暗部被抬到什么程度。

### 托盘运行

关闭按钮可在设置中选择「隐藏到托盘」或「直接退出」。最小化默认也隐藏到托盘：任务栏不再显示按钮，只保留右下角通知区域的图标，可在设置里改回留在任务栏。托盘菜单右键或通过快捷键可直接切换预设，也可以直接「重置所有显示器」（主界面只保留重置当前显示器的按钮）；退出时可选择「保留当前色彩」或「恢复默认色彩」。

### 关于与许可证

顶部菜单「帮助 › 关于 GammaLift」和托盘菜单的「关于 GammaLift」会打开同一对话框：显示版本号、两行版权、内置的 MIT 许可证全文与项目仓库链接。许可证全文收在程序内，便携版不需要额外的 LICENSE 文件；仓库链接用系统默认浏览器打开。

### 防重置与基线保护

首次见到某台显示器时捕获当前 Gamma LUT 作为基线（通常是系统 ICC / vcgt 校准曲线），之后的调节都叠加在基线之上。因此「重置」精确还原系统校准，而不是写一条线性表。可选「定时重新应用」，防止游戏或驱动重置色彩；睡眠唤醒、解锁、分辨率变化后自动恢复。

### 设置菜单与开机启动

「设置」菜单按「启动与权限 / 界面与语言 / 显示器 / 托盘与通知」分页，每项打开一个独立窗口；在「启动与权限」里勾选开机启动后写入当前用户 Run 键，启动时自动恢复上次设置。说明文字收在每组右上角的「ⓘ」悬停提示里；「解除极端数值限制」带独立小标题与说明。

## 使用提示

- 识别显示器：点「识别显示器」会在每台显示器中央闪现编号，对应下拉框里的 DISPLAY 编号。
- 极端数值不生效？Windows 默认限制 Gamma LUT 范围（防止显示器全黑或全白）。打开「设置 › 启动与权限」→「解除极端数值限制」，点「立即解除限制」（写入注册表 `GdiIcmGammaRange=256`，需管理员，注销后生效）。状态栏出现「部分数值被系统拒绝」时，点该提示也会直接跳到这一栏。
- 与 Windows 夜间模式、f.lux 的关系：两者都写 Gamma LUT，互相覆盖。首次运行（所有设置为默认值）时本应用不主动写 Gamma LUT，不会破坏夜间模式；一旦调整了某台显示器，该显示器的 Gamma LUT 以本应用为准。
- 设置文件默认位于 `GammaLift.exe` 同目录，文件名 `GammaLiftSettings.json`；若该目录不可写（如 Program Files 或只读共享），回退到「文档」文件夹下的同名文件。
- 退出时通过托盘菜单可选择「保留当前色彩」或「恢复默认色彩」。

## 技术说明

- 每显示器 Gamma：`CreateDC("\\.\DISPLAYn")` 加 `SetDeviceGammaRamp`（gdi32），各输出独立 Gamma LUT。
- DDC/CI：`dxva2.dll` Monitor Configuration API，VCP 码 0x10（亮度）、0x12（对比度）、0x8A（饱和度）。
- 公式（沿用经典 Gamma Panel 的公式）：`v = ((i/255)^(1/γ) − 0.5) × (对比度+100)/100 + 0.5 + 亮度/200`，逐通道生成 256 级 Gamma LUT。
- 基线按显示器硬件 ID 持久化在设置文件里，调节曲线在基线上复合采样。
