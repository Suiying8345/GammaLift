# 路线图

本文件列出 GammaLift 计划中的功能与改进，按优先级排列：越靠前的条目越先做。条目不附带发布时间。

## 近期

- 补齐 `docs/guide.md` 的「使用教程」章节：首次运行与 SmartScreen、识别显示器、建立一套提亮暗部配置、绑定全局热键、托盘与退出行为、多显示器同步

## 中期

- 分享码导入前预览：「导入分享码」窗口先解码并展示该码的亮度 / 对比度 / Gamma 参数，确认后再应用到当前显示器

## 远期

- 二进制代码签名：当前 `GammaLift.exe` 未签名，首次运行会触发 SmartScreen 告警。取得签名证书后随 Release 一并发布。
