# GammaLift 隐私政策

**生效日期：2026 年 11 月 14 日**

本隐私政策适用于 GammaLift Windows 桌面应用（以下简称「本应用」），说明本应用会接触哪些信息、这些信息保存在哪里，以及本应用不会做哪些事。

## 摘要

**本应用不联网，不收集任何个人信息。** 没有账号系统、没有广告、没有统计分析，也没有崩溃上报；本应用内不存在任何网络请求代码，全部功能可离线使用。你在本应用里调整的一切，只写在你自己电脑上的一个 JSON 文件里。

## 本应用接触的信息

本应用是本地工具，没有服务器，也没有接收数据的地方。下面这些信息只在本机产生、只在本机使用。

### 显示器标识与显示参数

- **显示器设备 ID**：由 Windows 提供的设备接口路径（含厂商与型号代码）。它只作为设置文件的键，让每台显示器的设置互相独立，并保证换接口、重新插拔后仍对应到同一台显示器。
- **显示参数**：亮度、对比度、Gamma、饱和度数值，软件 Gamma LUT 与硬件 DDC/CI 的通道选择，以及预设里的内容。
- **Gamma LUT 基线**：首次见到某台显示器时读到的当前 Gamma LUT（通常是系统 ICC / vcgt 校准曲线）。保存它是为了让「重置」能精确还原你原本的系统校准，而不是写一条线性曲线。

### 应用设置

界面语言、界面缩放比例、热键绑定与手势、通知开关、开机自启动状态、硬件面板展开状态等偏好。

保存位置：默认是与 `GammaLift.exe` 同目录的 `GammaLiftSettings.json`；该目录不可写时（例如放在 `Program Files` 或只读共享目录），改存到你的「文档」文件夹下的同名文件。

### 键盘输入（仅用于识别热键手势）

为了支持单击 / 双击 / 长按的全局热键，本应用在后台线程用键盘钩子观察按键的按下与抬起。它只比对按键码与时间间隔，判断是否命中你设置的手势：

- 按键内容**不会**被记录、保存、写入文件或发送出去；
- 不解析字符与输入法内容，也不针对特定窗口或程序做识别；
- 关闭全局热键或退出本应用后，钩子随即移除。

热键只在你主动设置并启用后才会注册；本应用不会为了「了解你按了什么」而监听键盘。

### 剪贴板（仅写入，不读取）

当你点「复制分享码」时，本应用把那段分享码文本写入 Windows 剪贴板。除此之外不碰剪贴板：导入分享码是**你自己**把文本粘贴进输入框，本应用不读取剪贴板内容。

### 注册表

只在你主动开启相应功能时写入，且只写两处：

| 位置                                                                              | 内容                         | 触发条件                                                                    |
| --------------------------------------------------------------------------------- | ---------------------------- | --------------------------------------------------------------------------- |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `GammaLift` 值        | `GammaLift.exe` 的完整路径 | 你开启「开机自启动」；关闭时删除该值                                        |
| `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ICM` 的 `GdiIcmGammaRange` | `256`                      | 你在「设置 › 启动与权限」中主动解除 Gamma 范围限制；需管理员权限，会弹 UAC |

两处都可随时撤销：关掉开关，或手动删除对应值。

## 本应用不会做的事

- 不收集、不上传、不出售、不共享任何个人信息或使用数据；
- 不含广告、追踪器、分析 SDK、崩溃上报，也不做自动更新检查；
- 不读取你的文档、图片、浏览记录、聊天内容或其他程序的输入；
- 不读取、不修改任何游戏或其他程序的内存与文件——本应用只改显卡 Gamma LUT 与显示器 OSD 参数，两者都属于显示输出；
- 不创建账号、不需要登录，也不需要联网即可使用全部功能。

## 数据的保留与删除

- 设置与基线全部在 `GammaLiftSettings.json` 中，删除该文件即清空所有设置（下次启动按默认值重建，基线会重新捕获）。
- 删除 `GammaLift.exe` 或不再使用本应用，**不会**自动删除该设置文件；需要时请自行删除。
- 注册表项按上文表格撤销。
- 本应用不写日志、不产生缓存，因此没有其他需要清理的运行记录。

## 第三方组件

本应用不引入任何第三方运行时库或内嵌 SDK，只调用 Windows 自带的系统组件，以及 .NET Framework 自带的程序集（如用 `System.Web.Extensions` 做 JSON 序列化）：

- **GDI32**：`GetDeviceGammaRamp` / `SetDeviceGammaRamp`，读写每台显示器输出的 Gamma LUT；
- **User32**：显示器枚举、全局热键注册、键盘钩子；
- **Dxva2**：DDC/CI 显示器配置（VCP 码 `0x10` / `0x12` / `0x8A`）。

这些系统组件受 Microsoft 的条款与隐私政策约束。本应用基于 [GammaPanelX](https://github.com/NiseMonox/GammaPanelX)（MIT 许可）重构，许可证与署名见仓库中的 [LICENSE](../LICENSE)。

## 儿童隐私

本应用是显示调节工具，不面向儿童设计，也不收集任何年龄或身份相关信息——本应用不收集任何信息。
